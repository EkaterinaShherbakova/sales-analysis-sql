# Анализ продаж (SQL)

## О проекте
Учебный проект по анализу продаж на SQL Server.  
Данные: 8 таблиц, 91 клиент, 196 заказов, 77 продуктов, 518 позиций заказов.

## Цель
Оценить структуру продаж: выручка по категориям, динамика по месяцам, концентрация клиентов, топы, география.

## Вопросы, на которые отвечает проект

1. **Топ-10 клиентов по выручке** - кто приносит больше всего денег
2. **Продажи по категориям** - сумма и доля каждой категории
3. **Динамика продаж по месяцам** - как менялась выручка
4. **Топ-3 продукта в каждой категории** - лидеры по выручке
5. **Средняя сумма заказа по клиентам** - кто покупает крупными заказами
6. **Клиенты без заказов** - потенциальная зона реактивации
7. **Активность по странам** - какие рынки ключевые

## Ключевые выводы

- **Beverages, Dairy Products, Confections** - топ-3 категории, вместе **58%** выручки
- **Топ-10 клиентов дают 51% выручки** - высокая концентрация
- **17 клиентов** (19%) не сделали ни одного заказа
- **USA, Austria, Germany** - лидеры по странам, вместе **44%** выручки
- Выручка **неравномерна** по месяцам, пик - **январь 1997**

## Инструменты
- SQL Server (T-SQL)
- Подзапросы, CTE, оконные функции, JOIN, GROUP BY, HAVING
